# WirelessRL
A simple research-oriented Python project for learning Reinforcement Learning through
beam selection in Massive MIMO wireless communication systems.

## Objectives

- Learn Reinforcement Learning from first principles.
- Build a wireless simulator from scratch.
- Implement RL algorithms ourselves.
- Compare with classical beam selection methods.
- Develop publishable research.
